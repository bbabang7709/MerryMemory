# MERRY MEMORY

**A Christmas Story for You**

크리스마스이브, 작은 눈 마을의 임시 집배원이 되어 흩어진 크리스마스카드 조각을 모으고 마지막 배달을 떠나는 2D 픽셀 퍼즐 어드벤처 게임입니다.
받는 사람이 누구인지는, 카드를 완성하면 알 수 있어요.

## 소개
- **장르:** 2D 픽셀 아트 / 퍼즐 / 어드벤처
- **플랫폼:** PC
- **플레이 타임:** 약 20~30분
- **성격:** 크리스마스 시즌 이벤트 게임

## 게임 방법
1. 임시 집배원 명찰에 이름을 적고 캐릭터를 고릅니다.
2. 마을 곳곳으로 흩어진 **카드 조각 5개**를 찾습니다.
3. 마을 사람들을 도와 퍼즐을 풀고, 받는 사람에 대한 단서를 모읍니다.
4. 자정 전에 카드를 완성해 배달합니다.

### 조작
| 키 | 동작 |
|---|---|
| WASD / 방향키 | 이동 |
| E / Space | 상호작용, 대사 넘기기 |
| ESC | 메뉴 |

## 개발 정보
- **엔진:** Unity 6 (6000.3.6f1)
- **렌더링:** URP 2D
- **주요 기술:** 2D Tilemap, Input System, TextMeshPro, ScriptableObject

## 현재 상태
기획을 마치고 Unity 프로젝트(Universal 2D 템플릿)를 생성한 단계입니다. 게임 기능은 아직 구현하지 않았습니다.

### 프로젝트 열기
Unity Hub에서 **Add → Add project from disk**로 이 저장소 폴더를 선택하고, Unity **6000.3.6f1** 버전으로 엽니다.
