## 1. 기본 수치

| 항목 | 값 |
|---|---|
| 바깥 마을 크기 | 64 × 48 타일 |
| 타일 1칸 | 32px = 1 unit (Pixels Per Unit 32) |
| 주인공 스프라이트 | 32 × 48px (가로 1칸, 세로 1.5칸), 피벗 발밑 중앙 |
| 카메라 한 화면 | 320 × 180 → 10 × 5.6칸 |
| 이동 속도 | 4칸/초 (`PlayerController.moveSpeed = 4`) → 마을 가로 16초 |
| 광장 ↔ 가장 먼 퍼즐(눈 언덕 연못) | 약 30칸, 걸어서 8초 안팎 |

### 좌표 규칙
- 이 문서의 좌표는 **(x, y) 타일 좌표**입니다. 원점은 지도 왼쪽 위, x는 동쪽, y는 **남쪽**으로 커집니다.
- 크기는 **w × h칸**이고, 위치는 오브젝트의 왼쪽 위 칸입니다.
- Unity 타일맵(위쪽이 +y)으로 옮길 때: **셀 = (x, 47 − y)**. 여러 칸짜리 오브젝트의 왼쪽 아래 셀은 `(x, 47 − (y + h − 1))`입니다.
- 실내 구역은 각 방의 왼쪽 위를 원점으로 한 별도 좌표입니다.

## 2. 구역 구성

광장 트리를 정중앙에 두고 네 퍼즐 구역을 동서남북에 나눴습니다.

```
 y  0 ┌──────────────────────── 숲 ────────────────────────┐
      │ 눈 언덕(고지대)   │ 바위 절벽 / 시계탑   │ 북동 주택가  │
      │  얼음 연못·리본   │      ▲ 앞마당        │  정자        │
 y 13 │──── 절벽, 계단 ───┤          │           │              │
      │ 공방 거리         │       광장 + 트리    │ 빵집 거리    │
      │  장난감 공방 ═════╪═══════  ★  ══════════╪═══ 빵집      │
 y 31 │ 남서 주택가       │ 우체국 │ 남쪽 큰길   │ 남동 개울가  │
      │                   │        │             │ ~~개울~~ 다리│
 y 47 └──────────────── 숲 ──── 입구 아치·눈 더미 ──── 숲 ─────┘
       x 0               x 22                    x 40          x 63
```

| 구역 | 대략 범위 | 들어 있는 것 |
|---|---|---|
| 눈 언덕 | x 2–20, y 2–12 (한 단 높은 고지대) | 얼음 연못 퍼즐, 리본 나무, 아이들, 썰매 슬로프 |
| 시계탑 앞 | x 22–37, y 2–16 | 시계탑, 앞마당 |
| 북동 주택가 | x 37–61, y 2–16 | 주택 2채, 전구 정자 |
| 공방 거리 | x 2–23, y 15–31 | 장난감 공방, 눈사람 공원 |
| 광장 | x 24–39, y 17–30 | 크리스마스트리, 게시판, 노점, 엔딩 무대 |
| 빵집 거리 | x 40–61, y 15–31 | 빵집, 주택 1채, 마켓 노점, 얼어붙은 분수 |

### 배치 원칙
- 어느 구역에서 돌아와도 광장을 지나게 해서 트리가 계속 눈에 들어오게 한다.
- 시계탑은 북쪽 축 끝의 랜드마크. 마을 어디서든 위쪽을 보면 방향을 잡을 수 있다.
- 우체국 분류함 4칸의 이름(시계탑 길·공방 길·빵집 길·눈 언덕)을 구역 이름과 맞춰, 튜토리얼에서 마을 구조를 미리 익히게 한다.
- 갈림길마다 방향 표지판을 두고, 진행에 필요한 오브젝트는 지나가며 보이는 자리에 놓는다.
- 마을 끝은 숲·절벽·개울·눈 더미로 막고 Cinemachine Confiner 2D 경계와 일치시킨다.

## 3. 진행 동선

| 단계 | 내용 | 장소 |
|---|---|---|
| 1 | 명찰 작성이 끝나면 우체국 실내 시작 위치에서 시작. 프롤로그(눈바람, 카드 흩어짐) | 우체국 실내 |
| 2 | **조각 ① 우표**: 흩어진 편지 6통을 분류함 4칸에 분류 → 우표·단서, 우체국 문 열림 | 우체국 실내 |
| 3 | 남쪽 큰길을 따라 광장으로. 게시판에서 글자 조각 ① | 광장 |
| 4 | **조각 ② 팝업 트리**: 공방 안에서 부품 3개를 찾아 장치 재조립 | 장난감 공방 |
| 5 | **조각 ③ 멜로디 칩**: 광장 콧노래 주민에게 멜로디 힌트 → 종탑에서 종 치기 | 시계탑 |
| 6 | **조각 ④ 리본**: 계단을 올라 얼음 연못을 미끄러져 리본 나무 밑까지 | 눈 언덕 |
| 7 | **조각 ⑤ 봉투**: 글자 조각 ②③을 찾아 번진 주소 복원 | 빵집 |
| 8 | 조각 5개를 모은 뒤 광장 트리 조사 → 카드 완성 → 엔딩 | 광장 |

4~7단계는 순서 없이 진행합니다. 글자 조각 3개는 모두 바깥에 있어서 어떤 순서로든 모을 수 있습니다.
